# Subhan Sikandar — Portfolio

A production-ready Next.js portfolio designed for frontend job applications and client-facing work.

## Highlights

- Next.js App Router + TypeScript
- No UI/animation dependency required beyond React/Next.js
- Interactive CSS 3D hero scene
- Mouse-responsive project card tilt
- Scroll reveal animations + scroll progress indicator
- Responsive/mobile layout
- Selected projects and real screenshots
- Downloadable CV
- SEO metadata
- Reduced-motion accessibility support

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy to Vercel

### Fastest method
1. Create a new GitHub repository.
2. Upload this project to the repository.
3. Go to https://vercel.com/new
4. Import the GitHub repository.
5. Keep the default Next.js settings and click **Deploy**.

### Vercel CLI

```bash
npm i -g vercel
vercel
```

## Update your information

Main content is in:

`components/Portfolio.tsx`

Change your projects, contact links, experience or skill text there.

`public/`

## Before publishing

- Replace/add a GitHub URL once you decide which GitHub profile you want to use.
- If you buy a custom domain, connect it in Vercel → Project → Settings → Domains.
- Keep the four strongest projects on the homepage; add more only if they show a different capability.
